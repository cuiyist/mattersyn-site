characterization

Construct dimers and trimers

Start two CdSe cores separated by an integer lattice translation. Add CdS/ZnS to set size and neck thickness. Restrict added layers to interface for area variation at fixed dot spacing/asymmetric trimers. For spacing variation at fixed neck thickness, split a fused dimer halfway along its bond, add lattice translations and duplicate interface atoms into the gap. Manually check intended structural parameters.
